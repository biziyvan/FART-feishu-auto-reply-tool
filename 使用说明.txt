========================================
  飞书自动回复助手 · 使用说明
========================================

【这是什么】
一个自动帮你回复飞书「AI教学平台」教学机器人的小工具。
它会自动监测机器人发来的题目，用大模型生成答案并发送。

【解压即用】
收到的是压缩包，解压到任意位置（桌面、D 盘都行），双击里面的
「飞书自动回复助手.exe」就可以用，不需要安装。
你的配置和登录状态保存在系统的用户目录里（见下文"文件说明"），
与解压位置无关，所以：
  · 解压到哪个文件夹都行，配置不会丢
  · 升级时把新版本解压到任意位置，配置和登录态照样沿用
  · 以后不用再重新填写密钥和网址

【升级与更新】
  · 收到新版本压缩包：解压到任意位置，双击新目录里的 exe 即可，
    配置和登录态都会自动沿用，不用重填。
  · 只收到「逻辑更新包-vX.X.X.zip」（通常是修 bug 的小更新）：
    不用换程序。双击打开本程序 → 点左下角「导入更新包」→ 选中那个 zip
    → 点「停止」再「启动监控」即可。
    （也可手动把 zip 里的 .py 解压到"数据目录"下的 app 文件夹）
  · 界面标题上会显示当前"逻辑版本"，形如 v1.0.7（内置）
    或 v1.0.7（外部更新）。

----------------------------------------
一、快速开始（3 步）
----------------------------------------

  第 1 步：解压压缩包，双击里面的「飞书自动回复助手.exe」
          （★整个文件夹要一起保留，不要只把 exe 单独拷出来）

  第 2 步：首次运行会弹出配置窗口，填 3 项：
         ① 飞书网页版地址
            —— 打开飞书网页版，从浏览器地址栏复制完整地址，
               形如 https://xxxxxx.feishu.cn/next/messenger/
         ② 机器人的会话名称
            —— 飞书左侧列表里那个机器人的名字，如「AI教学平台」
         ③ 大模型 API Key
            —— 用于生成答案的密钥（硅基流动 / DeepSeek 等都可以）

         填好后可点「测试连通性」验证密钥是否有效，
         然后点「保存并开始」。
         ★ 只需填这一次，以后都不用了。

  第 3 步：点「启动监控」。
         首次会打开一个浏览器窗口，请用手机飞书 App 扫码登录。
         登录一次即可，以后不用再登。

----------------------------------------
二、日常使用
----------------------------------------

  · 双击 exe → 点「启动监控」→ 保持程序运行即可
  · 浏览器窗口可以最小化，但**不要关闭**
  · 程序窗口中间是三个页签，会实时显示每一条回复：
       「运行日志」——完整的运行记录（可「跟随最新 / 复制 / 清屏」）
       「答题流水」——每答一题一行，一眼看清答了什么、发没发出去
       「配置与检查」——当前配置明细 + 运行前自检（想改配置点这里）
  · 想停就点「停止」按钮
  · 看不懂的操作用法，点左下角「使用说明」按钮可再看本说明
  · 想找配置 / 日志 / 登录态，点左下角「数据目录」按钮直接打开
  · 右上角「深色 / 浅色」按钮可切换主题（默认跟随系统）

  ★ 看到「[待命] 暂无新题，持续监控中…」是正常的，
    说明已答完当前题目，正在等机器人出下一题。

----------------------------------------
三、常见问题
----------------------------------------

  Q：双击没反应 / 闪一下就没了？
  A：可能是被杀毒软件拦截（这类打包程序常被误报）。
     把本程序加入杀毒软件白名单，再重新双击。

  Q：程序文件夹放在哪里？能移动吗？
  A：整个文件夹可以随便放（桌面、D 盘、U 盘都行），配置不会丢。
     注意：exe 需要和同一个文件夹里的 _internal 目录待在一起，
     不要只把 exe 单独拷出来。
     如果要连同数据一起拷贝到另一台电脑，见下方"换电脑"。

  Q：换电脑了怎么办？
  A：在新电脑上解压后双击 exe，首次会重新弹配置向导，重填一次即可
     （登录态需要重新扫码）。
     若想连配置一起搬，把旧电脑"数据目录"里的 config.yaml 拷到
     新电脑"数据目录"即可（见"数据目录在哪"）。

  Q：数据目录在哪？
  A：通常在：C:\Users\你的用户名\AppData\Local\飞书自动回复助手
     点界面上的「📂 数据目录」按钮可直接打开。
     里面就是配置、登录态和日志。

  Q：怎么做成"绿色版"（数据跟着 exe 走）？
  A：在 exe 旁边新建一个空文件，命名为 portable.txt，
     之后数据就会存到 exe 同级的文件夹里。（一般用不到）

  Q：提示找不到浏览器？
  A：本程序使用你电脑上的 Microsoft Edge。
     Win10 / Win11 都自带 Edge，一般无需额外安装。
     若确实没有，请到微软官网免费下载 Edge。

  Q：浏览器被别的窗口盖住了还工作吗？
  A：可以的，程序做了专门处理。但**不要关闭**浏览器窗口。

  Q：日志里出现"浏览器启动失败"？
  A：程序已自动重试 5 次并尝试自我修复（清理锁文件、结束残留
     浏览器进程）。若最终仍失败，日志里会给出处理步骤，按顺序做：
       ① 关闭所有 Edge 窗口，点「启动监控」重试
       ② 仍失败 → 打开"数据目录"，删除里面的 .browser_data 文件夹
          再启动（需重新扫码登录）
       ③ 仍失败 → 重启电脑后重试
     最常见的原因有两个：上次程序被强制结束，浏览器没退干净；
     或者 Edge 正在后台自动更新——等 1 分钟再点启动通常就好了。

  Q：启动后浏览器停在登录页不动了？
  A：这是首次运行的正常现象，需要你扫码登录飞书。
     用手机飞书 App 扫一下浏览器里的二维码即可，登录一次长期有效。
     日志会显示"需要登录，请扫码（最多等 3 分钟）"。

  Q：能开两个程序窗口吗？
  A：不能。程序会拦住第二次启动并提示"程序已在运行"。
     两个窗口会争抢同一个浏览器，必然有一个失败。

  Q：点了按钮没有任何反应？
  A：程序对每一步操作都会给出提示框。若真的毫无反应，
     请打开"数据目录"，把里面的 launcher_error.log 内容发给技术支持。
     该文件不存在，说明多半不是程序内部报错，而是被杀毒软件 / 系统策略拦截。

  Q：提示"保存失败"？
  A：说明当前目录不可写。首次运行请先确保能正常打开一次程序。

  Q：回复重复了 / 答非所问？
  A：先看日志。若持续出错，点「停止」再「启动」重启一次。

  Q：机器人换了一种出题方式，程序还认得出吗？
  A：认得出。程序支持三种出题形态：
     ①「AI 自适应问答」卡片；
     ②「学习反馈」末尾夹带的下一题；
     ③「请直接回复选项作答 / 当前题目：…」（这种常常不带题号）。
     三种都会正常作答，同一道题被平台反复推送也只答一次。

  Q：机器人让我"输入课程名"（如「如要开始学习，请输入课程名称，
    如[智能合约]」），程序会自动回复吗？
  A：会。遇到这类"只让你输入课程名、没有题目"的提示时，程序会自动
     回复一个课程名（默认「智能合约」）以开始/继续下一轮作答。
     想换成别的课程：点「数据目录」打开 config.yaml，改
       reply_strategy:
         auto_reply_course: "你的课程名"
     改成 ""（空）即可关闭这个自动回复。
     ★ 注意：改完要重启程序。平台在「学习反馈」里那句"需切换课程，
     直接发新的课程名（如「密码学基础」）"只是示例，程序**不会**误回。

  Q：写代码的题会怎么回答？
  A：给极简的核心代码，代码里不写注释，也不写异常处理、参数校验、
     多余函数这类"太完善"的东西，代码块后面用一句话说明关键行的作用。
     （机器人对代码题要求"说明关键行的作用"，这句不能省。）
     想改回答风格，见下方"想换模型或改配置"。

  Q：想换模型或改配置？
  A：切到「配置与检查」页签，点「修改配置」重新填写；
     或点「数据目录」打开 config.yaml 编辑。
     ★ 注意：编辑 config.yaml 后必须重启程序才会生效。

  Q：想改成 DeepSeek 官方接口（不用硅基流动）？
  A：在 config.yaml 里把 llm.base_url 改成 https://api.deepseek.com/v1、
     llm.model 改成 deepseek-flash，密钥换成 DeepSeek 的即可。
     ★ 参数不用你操心：程序按"接口地址"自动识别是哪家，
       硅基流动发 enable_thinking，DeepSeek 发 thinking:{type:disabled}；
       而且 DeepSeek 默认开着思考模式，程序会自动替你关掉（答题只回一个
       字母，开思考又慢又贵）。llm.provider 保持 "auto" 就好。
     （只有 base_url 填的是自建中转网关时，才需要把 provider 手填成
       siliconflow / deepseek 来告诉程序发哪套参数。）
     两种接口可以随时切换，配置和登录态都不用重填。

  Q：程序卡住 / 浏览器被锁住？
  A：按 Ctrl+Shift+Esc 打开任务管理器，
     结束所有 msedge.exe 和「飞书自动回复助手」进程后重启。
     （点「停止」按钮会连带关闭浏览器整棵进程，一般不会有残留。）

  Q：怎么更新历史对话（换课程后）？
  A：程序会自己读最新消息。如需重建历史，可在"数据目录"里
     删除 history.json 后重启。

  Q：出了新版本，要重新填密钥吗？
  A：不用。配置和登录态存在"数据目录"，跟解压位置无关。
     换新版本（解压到任意位置）或导入逻辑更新包，都不需要重填。
     详见开头"升级与更新"。

  Q：导入更新包后没变化？
  A：新逻辑在**下一次启动监控**时才生效。请点「停止」再「启动监控」。
     仍无变化，看标题上的"逻辑版本"是否已变成新版本号。
     （监控运行中导入会被拦下并提示——被替换的 .py 只在新进程里生效。）

  Q：点了「启动监控」，一秒后就变回"已停止"？
  A：新版会把子进程的退出码直接显示出来，形如
     「程序异常退出（代码 2）」。常见原因：
       · 代码 2  → 脚本没找到（更新包不完整，重新导入一次）
       · 其它    → 依赖缺失 / 脚本被改坏
     数据目录里的 live.log 记录了完整原因，把它发我即可排查。

  Q：程序自己不说话了 / 像是"悄悄失败了"？
  A：新版会把后台线程与未捕获的异常都写进
     数据目录里的 launcher_error.log（以前窗口程序没有控制台，
     这类异常会直接消失）。出问题先看这个文件。

----------------------------------------
四、文件说明
----------------------------------------

  飞书自动回复助手.exe   ← 主程序，双击它
  _internal\             ← 程序运行库（必须与 exe 待在一起，请勿删除或挪动）

  数据目录（默认 C:\Users\你的用户名\AppData\Local\飞书自动回复助手）：
    config.yaml            ← 你的配置（首次配置后生成，含 API Key）
    config.example.yaml    ← 配置模板
    .browser_data\         ← 浏览器登录态（扫码后生成）
    auto_reply.log         ← 运行日志（历史）
    live.log               ← 实时日志（与界面下方显示一致）
    launcher_error.log     ← 界面错误记录（排查用，正常时不存在）
    answered.json          ← 已答题目记录
    reply_stats.json       ← 问答统计
    app\                   ← 逻辑更新目录（只有点过「导入更新包」才会出现）

  ★ 整个程序文件夹可以随便放；数据都在上面的用户目录里，不会因移动文件夹而丢失。
  ★ app\ 里若存在与程序同名的 .py，会优先于 exe 内置的那份被使用——
    这就是"不换 exe 也能修逻辑"的原理。正常情况下你不需要碰它。
